# File guide

The five uploaded scripts are the source of the current master, cleaning, estimation, helper and graph files. Expenditure, climate and intermediate labelling helpers come from the pre-update repository.

| Stage | File | Role and execution |
|---|---|---|
| 00 | `00_master-dofile.do` | Main entry point; defines paths and enabled stages. |
| 01 | `do-files/01_data_cleaning.do` | Constructs household analysis data; normally called by the master. |
| 01.1 | `do-files/01.1_expenditure.do` | Called internally by cleaning; constructs expenditure aggregates. |
| 01.2 | `do-files/01.2_ihsvclimate.do` | Called internally by cleaning; processes and matches CRU climate data. |
| 01.3 | `do-files/01.3_var_labels.do` | Called internally by cleaning; constructs regime variables, applies labels and exports a codebook. |
| Local dependency | `do-files/004_labels.do` | Final labels pass; **not supplied or present in the repository**. |
| 02 | `do-files/02_MESR_main.do` | Main analysis and Word output; loads 02.1 automatically. |
| 02.1 | `do-files/02.1_MESR_programs.do` | Helper definitions, not a standalone analysis stage. |
| 03 | `do-files/03_graphs.do` | Optional alternative outcome distribution figures. |

Decimal numbering identifies dependencies, not separate analyses to run in filename-sorted order. Do not run cleaning helpers or 02.1 independently.

## Master settings

The supplied master retains installation `if (0)`, cleaning `if (1)` and estimation `if (0)`. The optional graph example is commented out. `global user 1` is retained; only user 1 has an implemented path block. Names of other collaborators in comments are not implemented path configurations.

## Cleaning

Inputs include raw IHS5 household/community/agriculture modules, the seasonal crop-unit conversion file, CRU weather inputs and the cleaning helpers. The optional reviewed harvest-conversion crosswalk is used only if present; no crosswalk was added by this update.

Important outputs under `$workingfiles` include `final esr data.dta`, `cleaning_audit.log`, `maize_crop_conversion_audit.dta`, `advice_topic_audit.dta`, `iv_and_merge_audit.csv`, `ihsvexp_o.dta`, `ihsvgeodetails.dta` and `ihsvcombined.dta`.

The intermediate labelling script also writes `working data.dta`, an earlier `final esr data.dta`, and `$result/codebook.xlsx`. Cleaning continues after that call and writes its final dataset later. Let the whole cleaner finish.

The climate helper expects `cru_pre_2.csv` and `cru_tmp_2.csv` under `$weather`. Its `runningscript_firsttime` setting remains `"Yes"`; matching and aggregation calculations are preserved.

## Estimation output

The original `10_15` suffixes are retained; renumbering scripts does not rename data, estimates or cache files.

| Output under `$result` | Contents |
|---|---|
| `MESR_tables_10_15.docx` | Main and appendix tables, with embedded figures. |
| `Fig2_outcomes_10_15.png` | Main distribution figure. |
| `Fig3_overlap_10_15.png` | Regime-probability overlap figure. |
| `MNP_10_15.ster` | Multinomial probit estimates. |
| `MNL_10_15.ster` | MESR multinomial logit first-stage estimates. |
| `MESR_main_trap_10_15.ster` | MESR bootstrap estimates. |
| `MESR_main_draws_10_15.dta` | Bootstrap draws. |
| `MESR_analysis_sample_10_15.dta` | Analysis sample and specification characteristics. |
| `07_MESR_main_10_15.log` | Main estimation log; original filename retained. |

Table numbering follows the uploaded estimation script:

- Tables 1–4: regime distribution, variable definitions, characteristics and unconditional differences.
- Table 5: multinomial probit coefficients and marginal effects.
- Tables 6–7: instrument tests and common support.
- Tables 8, 10, 12: regime-specific outcome equations.
- Tables 9, 11, 13: treatment effects and heterogeneity.
- Tables 14–15: coupled-versus-standalone comparisons and effect summary.
- Tables A1–A2: first-stage MNL and statistics referenced in the text.

The conceptual framework is not generated by these scripts. A separate robustness driver mentioned in the former header was not uploaded; having an IPWRA helper does not mean a robustness analysis runs automatically.

## Graph script

`03_graphs.do` preserves its original arguments and commands. It exports portrait and wide PNG/PDF versions of `Fig1_outcomes_by_regime_Manda`, plus panel PNGs. This numbering differs from the main estimation file's Figure 2. Use the saved analysis sample to match the estimation population. The graph script can append to an already-open Word document, but does not save a standalone Word report.

## Historical scripts

`legacy/` retains earlier repository source files byte-for-byte. They are reference copies, not another supported workflow. Their original paths have not been rewritten; do not mix their globals, instruments or estimators with the current files.
