# Follow-up audit: 20 October 2026

## What failed in the first package

The latest five supplied scripts were documented and renamed, but expenditure, climate and earlier labeling helpers were taken from older repository versions. Preserving each file separately did not verify compatibility across those versions. The package should not have been described as fully runnable or numerically replicated.

## Repairs in this revision

- `01.3_var_labels.do`: retain `maize`, `lat`, `lon`, `GPS_lat` and `GPS_lon` in the existing keep-list. The caller uses them later. This retains existing values; it does not construct substitutes or change observations.
- `01.2_ihsvclimate.do`: use the existing local `cru_clim_vars` temporary-file handle in the final grid merge. The previous expression expanded to a different, undefined local name.
- `01_data_cleaning.do`: check for the original `004_labels.do` before constructing or overwriting datasets. If absent, stop with an explicit explanation. No substitute label script has been invented.
- README: correct the distinction between multinomial probit determinants and the multinomial logit used for the MESR correction; state the incomplete validation status prominently.

These are compatibility repairs, not a redesign of cleaning or estimation. The original earlier label helper also constructs variables and saves datasets; despite its filename it is not purely a labeling script.

## Report comparison and remaining requirements

The available reference report, `MESR_results_main_10_10.docx`, contains 7,749 analysis households (3,576 neither; 451 FISP only; 3,164 SAPs only; 558 both). Its Table 2 mean productivity is 351.22 kg/acre, HDDS 7.35 and FCS 43.77. These are comparison targets, not verified outputs of this revision.

The supplied main script writes 10_15 output and uses revised table numbering/layout. For example, its multinomial probit table is Table 5 while the 10_10 report uses Table 3. It therefore cannot be promised to reproduce that document's exact layout without a separately authorized table-format change. The script also prefers `final_esr_data.dta` over `final esr data.dta` if both exist: confirm which dataset belongs to the report before executing. No precedence was silently changed.

The supplied cleaner contains substantive outcome mean-replacement blocks (including regime-dependent replacements) before winsorization. Those blocks were preserved as requested; preserving them is not an endorsement or verification of their analytical appropriateness. Removing them would change the analysis and could change the report results.

The report itself includes implied rho values outside [-1,1], including 1.1247 for HDDS and 1.2114 for FCS. Documentation changes cannot resolve those estimates; they have not been clipped or concealed.

A full-run claim still requires:

1. The actual final-label dependency `004_labels.do` and confirmation that the older three helpers are the intended versions.
2. The exact analysis dataset and matching final reference report (10_10 or 10_15).
3. Execution in Stata 17+ with raw inputs and required commands, followed by a table-by-table numerical comparison.

Stata is not installed in this execution environment. No native Stata run, bootstrap execution or numerical reproduction was performed. The present checks establish source preservation and repair identified integration defects; they do not certify that no other runtime issue remains.
